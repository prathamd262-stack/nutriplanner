NutriPlanner — Multipage-style Interface Mini Project
=====================================================

WHAT IS INCLUDED
- Login screen and create-account screen
- Separate app pages for Overview, Explore Meals, My Meal Plan, Healthy Habits, and Account
- The app pages switch without a long scrolling page
- Responsive layout for desktop and mobile
- Food photo cards and category filters
- Add/remove meal planner
- Favourite buttons
- Water tracker

LANGUAGES
HTML, CSS, JavaScript.

HOW TO RUN
1. Extract NutriPlanner_Multipage_Mini_Project.zip.
2. Open the NutriPlanner_Multipage folder.
3. Double-click index.html.
4. Use any email and any password to sign in to the demo.

IMPORTANT LOGIN NOTE
The login is a front-end demonstration only. It is NOT secure real authentication and does not verify a password. Do not use a real password. A real system requires a backend and secure authentication.

PHOTOS
Food photos and Google Fonts are loaded online, so an internet connection is needed for them.

PRESENTATION SUMMARY
"NutriPlanner is a meal-planning website with a login interface and separate sections for the dashboard, meal ideas, daily plan, healthy habits, and account. HTML builds the page structure, CSS creates the colourful interface, and JavaScript manages navigation and interactive features."
